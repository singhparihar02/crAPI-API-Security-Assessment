# crAPI Security Assessment Report

This folder contains the PDF report documenting my hands-on API security assessment of OWASP crAPI (Complete Ridiculous API).

## Report Details

- **Target:** OWASP crAPI
- **Environment:** Local Docker deployment
- **Testing Tools:** Burp Suite Community Edition and JWT Editor extension
- **Assessment Type:** API Security Testing

## Report Contents

The report covers practical testing scenarios involving authentication, authorization, access control, injection, rate limiting, mass assignment, and JWT security.

## Disclaimer

This assessment was conducted in a controlled local lab environment using an intentionally vulnerable application for educational and security learning purposes.
